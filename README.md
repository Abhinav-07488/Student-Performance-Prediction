# Student-Performance-Prediction
A Student Performance Prediction web application built using Python and Streamlit to collect student details and predict academic performance using machine learning

A Machine Learning project that predicts a student's estimated final mathematics grade using academic and personal study-related features.

## Project Overview

This project uses supervised Machine Learning to estimate the final student grade (`G3`) on a scale of 0–20. It includes data preprocessing, model training, evaluation, exploratory data analysis, and an interactive Streamlit web application.

## Features

- Automatic dataset download
- Data preprocessing using Scikit-learn pipelines
- Missing-value handling and categorical encoding
- Random Forest regression model
- Model evaluation using MAE, RMSE, and R²
- Exploratory Data Analysis (EDA) with visualizations
- Interactive Streamlit prediction interface
- Comparison of Linear Regression, Decision Tree, and Random Forest

## Installation and Usage

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Student-Performance-Prediction
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Train the model

```bash
python train.py
```

### 4. Generate EDA visualizations

```bash
python eda.py
```

### 5. Compare Machine Learning models

```bash
python compare_models.py
```

### 6. Launch the web application

```bash
python -m streamlit run app.py
```

## Model Evaluation

The project evaluates regression performance using:

- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **R²:** Coefficient of Determination

Actual scores should be taken from the output generated by running the training and model comparison scripts.

## Dataset

The project uses the UCI Student Performance dataset. The application provides educational estimates and should not be used as the sole basis for academic decisions.
